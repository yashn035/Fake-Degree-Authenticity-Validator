# EduVerify AI: Authenticity Validator for Academia

An enterprise-grade, automated authenticity validator designed to detect tampered academic certificates in seconds using AI-powered OCR, cryptographic perceptual hashing, and a centralized fraud intelligence dashboard.

## 🌟 Key Features (15+)
1. **AI-Powered OCR Data Extraction** (Tesseract.js)
2. **Cryptographic Perceptual Hashing** (Image-Hash)
3. **Automated Mismatch Detection & Field Highlighting**
4. **Role-Based Access Control & JWT Authentication**
5. **Dynamic PDF Report Generation** (Cryptographically signed)
6. **Instant Verification QR Codes** (Shareable links)
7. **Digital Anti-Forgery Watermarking**
8. **Enterprise Admin Dashboard**
9. **Global Certificate Blacklist System**
10. **Bulk CSV/JSON Import for Institutions**
11. **Real-time Fraud Intelligence Trends**
12. **Dark Mode UI & Micro-animations**
13. **Robust API Security & File Validation**
14. **One-Click System Reset (Killswitch)**
15. **Fully Dockerized One-Command Setup**

## 💻 Tech Stack
- **Frontend:** React, Vite, TailwindCSS, React Router, Recharts, Lucide Icons
- **Backend:** Node.js, Express.js, SQLite3, Bcrypt, JSONWebToken, Multer
- **Services:** Tesseract.js (OCR), sharp (Image Processing), pdf-lib (PDF Generation), qrcode (QR Generation)

## 🚀 Setup Instructions
Ensure you have Node.js 18+ installed.

```bash
# 1. Install dependencies for the entire project
npm install

# 2. Start both Frontend and Backend servers simultaneously
npm run start:all
```
*Frontend runs on `http://localhost:5173` | Backend runs on `http://localhost:5000`*
