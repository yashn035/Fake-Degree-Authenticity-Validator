# 🚨 Demo Day Emergency Kit

Keep this open during your presentation!

## 🔄 Emergency Reset
If the system gets stuck or cluttered with bad data during a live demo, trigger the **Killswitch**:
1. Go to the Admin Dashboard.
2. **Triple-click** the blue Activity icon in the top left corner next to the title.
3. The database will truncate, re-seed with clean data, and the page will reload.

## 🛜 WiFi Fallback Plan
If the venue WiFi drops:
1. Don't panic. The system runs 100% locally on `localhost`.
2. Do **not** refresh the browser (to keep the React app in memory).
3. Continue the demo normally.
4. If asked, mention: "Our architecture supports complete offline-first edge deployment."
